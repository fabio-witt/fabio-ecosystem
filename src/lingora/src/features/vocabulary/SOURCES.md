# Vocabulary data sources

The thematic lists are taken from the supplied Fabio Ecosystem v73 LERNWERK archive. The import aligns target-language entries with the English glossary and selects 20 distinct entries per theme. Context comes from the archive's GrammarFirst lessons, LERNWERK lessons and short readings.

The ranked lists are filtered extracts of three independent sources. Filtering removes duplicates, fragments and non-word entries. The Zurich list counts case-normalised tokens in the Zurich reference texts.

- German, English, Spanish, French, Italian, Polish and Russian: [Hermit Dave, FrequencyWords 2018](https://github.com/hermitdave/FrequencyWords), derived from OpenSubtitles. Data is [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- Irish: [Michal Boleslav Měchura, Irish Word Frequency List](https://github.com/michmech/irish-word-frequency), derived from the New Corpus for Ireland. The extract is available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
- Zurich German: [Noëmi Aepli, Chantal Amrhein, Florian Schottmann and Rico Sennrich, Zurich German NTREX references](https://aclanthology.org/2023.wmt-1.99/), distributed via [Microsoft NTREX](https://github.com/MicrosoftTranslator/NTREX). Data is [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The relevant data licenses apply to the respective extracts in `frequency.json`.
