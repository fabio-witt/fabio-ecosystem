# Release Notes v66

## GrammarFirst
* Meilensteine A1 bis C2 im Lernpfad jeder Sprache. Nach dem letzten Kapitel eines Niveaus erscheint der Meilenstein mit Fortschritt, Kann-Beschreibung und Zertifikat. Niveaus ohne Kurse (B2, C1, C2) sind als "in Arbeit" sichtbar.
* Aktuelles Niveau als Abzeichen im Kurskopf.
* Hinweis: Die Meilensteine bestätigen die Grammatik eines Niveaus, sie ersetzen keine offizielle Prüfung.
* Erklärsprache standardmässig Englisch, auch die App-Oberfläche. Umschaltbar in Profil > Einstellungen (Sprache der Erklärungen) und beim Start mit DE/EN.
* Englische Erklärungen für Spanisch, Französisch, Russisch, Polnisch, Züridütsch, Italienisch und Irisch (rund 1850 Texte). Deutsch wird weiterhin auf Englisch erklärt, Englisch auf Deutsch.
